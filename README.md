
# PropConnect Lokoja

## 1. Project Title
**PropConnect Lokoja — Real Estate Property Listing and Management Platform**

## 2. Project Description
PropConnect Lokoja is a responsive website designed to make it easier for people to find properties for rent and sale in Lokoja, Kogi State, Nigeria. Users can search for properties by neighbourhood, property type, and purpose, view property details, save favourite properties, and make enquiries. The project aims to provide a simple and organised property-search experience within Lokoja.

## 3. Features
- Responsive and modern user interface.
- Property listings for rent and sale.
- Search and filter properties by neighbourhood, type, and purpose.
- View property details, prices, and features.
- Save and remove favourite properties.
- Browse properties by neighbourhood.
- Share property information.
- Contact and property enquiry form.
- Mobile-friendly navigation.

## 4. Technologies Used
- **HTML5:** Structures the website content.
- **CSS3:** Styles the website and makes it responsive.
- **JavaScript:** Adds interactive features, property filtering, favourites, and property details.

## 5. How to Run the Project
1. Download or clone the project repository from GitHub.
2. Open the project folder in Visual Studio Code.
3. Ensure that `index.html`, `css/style.css`, and `js/main.js` are in their correct locations.
4. Open `index.html` in your web browser.
5. Alternatively, install the Live Server extension in VS Code, right-click `index.html`, and select **Open with Live Server**.
